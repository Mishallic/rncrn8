# Contributing

Thank you for taking a look.

**Welcome:**

- **Issues**: bugs, install problems (please say your operating system and how you installed),
  confusing output, and ideas.
- **Outcome reports**: if you used rncrn8 on your own work and recorded which findings turned
  out right or wrong, an issue with the **Outcome report** template is the most useful thing
  you can send. It asks for the output of `rncrn8 replay --without-learning`. Please leave out
  anything confidential; numbers and a sentence are enough.
- **Security problems**: see [SECURITY.md](SECURITY.md); please report them privately.

**Not accepted for now: pull requests.** rncrn8 is maintained by one person. For the first six
weeks after the 0.2.0 release, issues get answered actively; after that, on a best-effort
basis. There is no capacity to review outside code. A pull request will be closed without
review; an issue describing the change is the way to propose one.
